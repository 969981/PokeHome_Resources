## 3. 证据等级与命名边界

| 等级 | 数量 | 是否能写具体游戏业务用途 |
|---|---:|---|
| `VERIFIED_NATIVE_STATIC` | **37** | 有静态机器码/转换链证据，可以具体描述已验证部分 |
| `SYMBOL_EVIDENCE` | **1,545** | 只报告已有符号名称，不从名称推断全部副作用 |
| `BEHAVIOR_OBSERVED` | **13,833** | 报告同步、内存、分支、返回等操作特征；**真实游戏业务用途待确认** |

在这个规则集下，很多未知业务函数被归入 `BEHAVIOR_OBSERVED`，因此不能把“零个 UNRESOLVED 标签”理解为“所有函数用途已经破解”。

指令级覆盖包括读写内存、计算、分支、直接或间接调用、返回、原子同步、提示/指针认证以及未能具体分类的指令。遇到未识别的 Mnemonic，注释明确写待复核，不猜测操作效果。

## 4. 特别核对的三个重点原生函数

### `main+0x50E994`：PH4 SideData 迭代边界

实际 8 条指令的行为：

| PC | 指令 | 说明 |
|---|---|---|
| `0x50E994` | `LDR X8,[X0,#8]` | 从包装对象取内部记录指针 |
| `0x50E998` | `SUB X9,X1,X8` | 计算游标的记录内偏移 |
| `0x50E99C` | `LDRH W8,[X8,#0xD6]` | 取 SideDataLength |
| `0x50E9A0` | `SUB X9,X9,#0x10` | 去掉 Header 开销 |
| `0x50E9A4` | `ADD X8,X8,#0xC8` | 组合 Core 与 SideData 长度界限 |
| `0x50E9A8` | `CMP X9,X8` | 比较游标和界限 |
| `0x50E9AC` | `CSET W0,LO` | 小于界限返回 true |
| `0x50E9B0` | `RET` | 返回；**本函数未匹配 Tag ID** |

对合法游标/长度，边界相当于 `cursor < record + 0xD8 + SideDataLength`。

### `main+0x5306B4`：EH4 带 CRC 检查的解密

原生 `0x5306F8` 调用 `0x530120` 计算 CRC；`0x530704` 调用 `0x53041C` AES-CBC 解密；`0x530708` 比较 CRC；`0x530714` 在不匹配时更新 Invalid 标志。此链属于**本地 EH4 处理**，不能据此证明服务器已接受保存。

### `main+0x5106D0`：线程同步和 7 路状态分派

Ghidra C 证实存在 ExclusiveMonitor、DataMemoryBarrier、`nn::os::WaitLightEvent` 和间接分派。可安全备注为“同步/分派代码”，而非未经证实的 ServerSaveManager。

## 5. 一键还原注释 SQLite

在仓库根目录：

```powershell
python tools/ghidra/home41_restore_annotations.py --source derived/4.1.0/Ghidra_12.2_Run_42763137320/annotation_v1 --out D:\HOME41_annotations.sqlite
```

它会按清单对每个分片 SHA256 验证、原始字节拼接、再次验证完整 SHA256，然后执行 `PRAGMA integrity_check` 和行数检查。可查询：

```sql
SELECT entry, rva, label, purpose, evidence_level
FROM function_annotations
WHERE evidence_level = 'VERIFIED_NATIVE_STATIC'
ORDER BY rva;

SELECT addr, mnemonic, display_text, behavior_class, comment
FROM instruction_annotations
WHERE addr LIKE '%0060e994';

SELECT evidence_level, COUNT(*)
FROM function_annotations GROUP BY evidence_level;
```

`main+RVA` 与 Ghidra `.text::ADDRESS` 地址域需要按本文件的 Image Base `0x100000` 换算，不能把两者直接当作同一地址。
